chat-tutor 실습 허브

각 페이지에 필요한 서버가 적혀 있다. 자세한 실행법은 QUICK_START.md

2단계 · 실시간 통신과 인증

  • 07 순수 WebSocket 서버: ./gradlew :server:raw-websocket:bootRun
  • 08~09 STOMP 채팅 · heartbeat · 재연결 서버: ./gradlew :server:stomp-chat:bootRun
  • 12 JWT 로 보호된 STOMP 서버: ./gradlew :server:secure-chat:bootRun + npm run tenant

3단계 · 화면 동기화 (서버 없이 브라우저만)

  • 13 DOM 이벤트 · 전파 · isTrusted · property vs attribute
  • 15~16 스냅샷 + MutationObserver 로 화면 복제 (같은 페이지 안에서)
  • 17 에코 루프 재현과 방지

4단계 · 최종 프로젝트: 화면 공유 상담

서버: ./gradlew :server:cobrowse-server:bootRun + npm run tenant

  • 고객 페이지 (보험 가입 화면 + SDK)
  • 상담사 콘솔

두 창을 나란히 띄워 놓고 고객 페이지에서 입력·스크롤해 보자. 클러스터 실습은 4-practical/23 README 참고.
