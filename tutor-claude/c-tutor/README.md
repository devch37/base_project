# C 실무형 학습 프로젝트 (c-tutor)

> **작은 프로그램들을 직접 만들며** C를 basic부터 advanced까지 배웁니다.
> 목표: **읽고 나면 실무 C 코드베이스와 오픈소스 프로젝트에 바로 투입될 수 있는 수준.**

- 컴파일러: `clang` 또는 `gcc` (C11 표준 기준, C99/C17 차이도 설명)
- 빌드: `make` (Makefile 하나로 모든 예제 컴파일) + 18장에서 CMake
- 디버깅: `lldb`/`gdb`, AddressSanitizer, UndefinedBehaviorSanitizer, Valgrind
- 모든 예제 코드에 **왜 그렇게 쓰는지**까지 담은 한글 주석
- 초등학생에게 설명하듯 쉬운 비유 → 그다음 실무 수준의 정확한 설명

---

## 이 프로젝트를 관통하는 하나의 질문

> **"이 코드가 실행될 때 메모리에서는 정확히 무슨 일이 일어나는가?"**

C를 안다는 것은 문법을 아는 게 아니라 **메모리와 실행 모델을 머릿속에 그릴 수 있다**는 뜻입니다.
모든 장이 이 그림을 조금씩 채워 나갑니다.

---

## 빠른 시작

```bash
cd c-tutor
make                 # examples/ 아래 모든 .c를 bin/으로 컴파일
make list            # 실행 가능한 예제 목록
./bin/01_hello       # 예제 하나 실행
make run NAME=01_hello   # 위와 동일 (탭 자동완성이 안 될 때)
make 06              # 6장 예제만 다시 빌드
make asan NAME=08_leak  # AddressSanitizer 켜고 빌드+실행
make clean
```

문제가 없다면 아래가 출력됩니다.

```
$ ./bin/00_hello
안녕하세요, C의 세계에 오신 걸 환영합니다.
이 문장은 컴파일러가 기계어로 번역해서, CPU가 직접 실행한 결과입니다.
```

> 컴파일러가 없다면 [docs/00](./docs/00-환경설정과-컴파일-파이프라인.md)의 설치 안내를 먼저 보세요.

> **`make` 중 일부 예제는 일부러 경고를 냅니다** — `00_warn`(경고의 위험성),
> `02_conversions`(부호 비교), `05_lifetime`(지역변수 주소 반환),
> `07_array_decay`(배열 파라미터 sizeof). 컴파일러가 버그를 어떻게 잡아 주는지
> 보여 주는 게 목적이며, 각 파일 주석에 설명이 있습니다. 그 외 경고가 나면 알려 주세요.

## 권장 학습 방법

1. **먼저 `docs/NN` 을 읽는다.** 비유로 감을 잡고, 개념 설명을 정독합니다.
2. **`examples/NN/` 의 코드를 열어 주석까지 읽는다.** 그리고 직접 컴파일해 실행합니다.
3. **일부러 부순다.** 포인터를 NULL로 바꿔 보고, `free`를 두 번 호출해 보고,
   배열 경계를 넘어 봅니다. `make asan NAME=...` 으로 새니타이저가 뭐라고 하는지 봅니다.
4. **`exercises/NN` 문제를 푼다.** 막히면 해답을 보되, 왜 그런지 설명할 수 있을 때까지 봅니다.
5. 3~4개 장마다 한 번씩 앞 장을 복습합니다. C는 **누적형** 언어입니다.

> "일부러 부수는" 3번이 이 학습에서 가장 중요합니다.
> C의 위험한 부분을 안전한 환경에서 미리 만나 두는 것이 실무 대비의 핵심입니다.
