# 12. 표준 라이브러리 투어

> 목표: 실무에서 매일 쓰는 표준 헤더들의 **핵심 함수와 함정**을 한 번에 훑는다.
> "이런 게 있다"를 알아야 바퀴를 다시 발명하지 않습니다.

C 표준 라이브러리는 작습니다(파이썬 대비 1/100). 그래서 다 알 수 있습니다.

---

## 1. `<stdio.h>` — 입출력

```c
printf / fprintf / snprintf / sprintf
scanf  / fscanf  / sscanf
fopen / fclose / fread / fwrite / fgets / fputs / fgetc / fputc
fseek / ftell / rewind / feof / ferror
perror / setvbuf
```

### 서식 지정자 (외워 두면 평생 씀)

| 지정자 | 타입 | 비고 |
|---|---|---|
| `%d` `%i` | `int` | |
| `%u` `%x` `%o` | `unsigned` | `%#x` 는 `0x` 접두 |
| `%ld` `%lld` | `long` `long long` | 크기 접두사 필수 |
| `%zu` | `size_t` | `sizeof` 결과 출력 시 |
| `%f` `%g` `%e` | `double` | `float` 도 자동 승격됨 |
| `%.2f` | | 소수 2자리 |
| `%s` | `char *` | **`NULL` 넘기면 UB** (glibc는 봐주지만 표준 아님) |
| `%p` | `void *` | 포인터. `(void *)` 로 캐스트 |
| `%c` | `int`(문자) | |
| `%%` | 리터럴 `%` | |

### 함정
- **`scanf` 는 피하세요.** 공백/개행 처리가 직관과 다르고, `%s` 에 길이 제한이 없으면 버퍼 오버플로우.
  → `fgets` 로 한 줄 읽고 `sscanf`/`strtol` 로 파싱 (13장).
- `printf` 반환값 = 출력한 문자 수(음수면 에러). 보통 무시하지만 파이프가 닫히면 확인 필요.
- **버퍼링**: `stdout` 은 터미널이면 줄 단위, 파이프면 블록 단위 버퍼. 크래시 직전 `printf` 가
  안 보일 수 있음 → `fflush(stdout)` 또는 `stderr`(버퍼 없음) 사용, 디버그 시 `setvbuf`.
- `sprintf` 금지, `snprintf` 만. `snprintf(NULL, 0, fmt, ...)` 로 필요한 길이를 먼저 계산 가능.

## 2. `<string.h>` — 메모리/문자열 조작

```c
strlen strcmp strncmp strchr strrchr strstr strspn strcspn strtok
strcpy strncpy strcat strncat            // 위험: 크기 검사 없음/불완전
memcpy memmove memset memcmp memchr
strerror                                  // errno -> 사람이 읽는 문자열
```

### 반드시 기억할 것
- `memcpy` 는 영역이 **겹치면 UB**. 겹칠 수 있으면 `memmove`.
- `strncpy` 는 보안 함수가 **아닙니다**: 소스가 길면 널 종단을 안 붙이고, 짧으면 나머지를
  전부 `\0` 로 채웁니다(느림). `snprintf` 나 `strlcpy`(BSD)를 쓰세요.
- `strtok` 는 내부에 정적 상태 → **스레드 안전 아님**, 원본 문자열을 **파괴**함. `strtok_r` 사용.
- `strcmp` 반환값은 `<0 / 0 / >0` 이지 `-1/0/1` 이 아닙니다.
- `memset(p, 0, n)` 으로 구조체 초기화는 OK지만, 포인터를 "0"으로 만드는 게 모든 플랫폼에서
  널 포인터라는 보장은 이론상 없음(실무에선 사실상 안전).

## 3. `<stdlib.h>` — 잡화점

```c
malloc calloc realloc free
atoi atof strtol strtoul strtod          // 문자열 -> 숫자
qsort bsearch                            // 14장에서 자세히
rand srand                               // 품질 낮음. 보안/시뮬레이션엔 부적합
abs labs div
exit atexit _Exit abort
getenv system                            // system() 은 보안 위험 (20장)
```

- **`atoi("abc")` 는 0을 반환** (에러 구분 불가). 실무에선 `strtol` + `errno` + `endptr` 검사:

```c
errno = 0;
char *end;
long v = strtol(s, &end, 10);
if (end == s || *end != '\0' || errno == ERANGE) { /* 파싱 실패 */ }
```

- `exit()` 는 `atexit` 핸들러 실행 + 스트림 flush. `_Exit()`/`abort()` 는 안 함.
- `rand() % n` 은 편향됩니다. 범위 난수는 나눗셈 방식 대신 rejection sampling.

## 4. `<math.h>` — 수학 (링크 시 `-lm` 필요할 수 있음, 리눅스)

```c
sqrt pow fabs floor ceil round trunc fmod
sin cos tan atan2 exp log log2 log10
fmin fmax
isnan isinf isfinite                     // NaN 은 자기 자신과도 != (x != x 로 NaN 검사 가능)
INFINITY NAN M_PI(비표준, 보통 있음)
```

- 정수 `pow` 는 없음. `pow(10, 2)` 가 `99.999...` 가 될 수 있으니 정수 거듭제곱은 직접 루프.
- `0.0/0.0` = NaN, `1.0/0.0` = inf (부동소수점에선 UB 아님, 정수 0 나누기는 UB).

## 5. `<time.h>` — 시간

```c
time(NULL)              // 1970년 이후 초 (time_t)
clock()                 // CPU 시간 (CLOCKS_PER_SEC 로 나눔) — 벤치마크용
difftime(t2, t1)        // 초 차이 (double)
struct tm, localtime, gmtime, mktime, strftime
```

- `localtime`/`gmtime` 은 **정적 버퍼 반환** → 스레드 안전 아님. `localtime_r` 사용.
- 정밀 측정은 POSIX `clock_gettime(CLOCK_MONOTONIC, ...)` (17장 프로파일링).

## 6. `<assert.h>` — 계약 검사

```c
#include <assert.h>
assert(ptr != NULL);           // 거짓이면 stderr 에 메시지 + abort()
assert(index < len && "인덱스 범위 초과");   // 관용구: && "설명"
```

- `-DNDEBUG` 로 컴파일하면 **모든 `assert` 가 사라집니다**. 그래서:
  - `assert` 안에 **부수 효과를 넣지 마세요**: `assert(pop(stack) == 5);` → 릴리스에서 pop 안 됨.
  - `assert` 는 "프로그래머의 실수(버그)"용. "사용자 입력 검증"은 `assert` 가 아니라 정상 에러 처리.
- C11 `_Static_assert(cond, "msg")` — 컴파일 타임 검사 (구조체 크기, 타입 가정 등).

## 7. `<stdint.h>` / `<stdbool.h>` / `<stddef.h>` / `<limits.h>` / `<stdnoreturn.h>`

```c
<stdint.h>   int32_t, uint64_t, INT32_MAX, SIZE_MAX, intptr_t, PRIu64(<inttypes.h>)
<stdbool.h>  bool, true, false  (C23부터는 키워드)
<stddef.h>   size_t, ptrdiff_t, NULL, offsetof
<limits.h>   INT_MAX, CHAR_BIT(항상 8은 아님, 보통 8), LONG_MIN ...
<stdnoreturn.h> noreturn  (돌아오지 않는 함수: exit 래퍼 등)
```

`printf` 로 `int64_t` 출력: `printf("%" PRId64 "\n", x);` (`<inttypes.h>`).
