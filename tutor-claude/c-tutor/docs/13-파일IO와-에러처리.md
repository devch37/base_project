# 13. 파일 I/O와 에러 처리

> 목표: `FILE *` 스트림 I/O, 텍스트 vs 바이너리, `errno` 규약,
> C의 에러 처리 관용구(반환값 + `goto cleanup`), 부분 읽기/쓰기 처리.

---

## 0. 초등학생 버전 비유

파일을 다루는 건 **도서관 책을 빌리는 것** 같습니다.
- `fopen` = 대출 (성공하면 대출증 `FILE *`, 실패하면 `NULL`)
- `fread`/`fwrite` = 읽기/필기
- `fclose` = 반납 (안 하면 다음 사람이 못 읽고, 필기한 게 저장 안 될 수도)
- `errno` = "왜 안 됐는지 적힌 쪽지" — 단, **다음 실패가 덮어쓰기 전에** 읽어야 합니다.

---

## 1. 스트림 열고 닫기

```c
FILE *fp = fopen("data.txt", "r");
if (fp == NULL) {
    perror("data.txt");          // "data.txt: No such file or directory"
    return -1;
}
/* ... */
if (fclose(fp) != 0) {           // fclose 도 실패할 수 있다 (버퍼 flush 실패 등)
    perror("fclose");
}
```

### 모드 문자열

| 모드 | 뜻 |
|---|---|
| `"r"` | 읽기. 파일 없으면 실패 |
| `"w"` | 쓰기. **기존 내용 삭제**. 없으면 생성 |
| `"a"` | 추가. 항상 끝에 씀. 없으면 생성 |
| `"r+"` | 읽기+쓰기. 파일 있어야 함 |
| `"w+"` | 읽기+쓰기. 내용 삭제 |
| `"rb"`, `"wb"` ... | **바이너리 모드** — Windows에서 `\r\n` 변환을 막음. 이식성 위해 바이너리 파일엔 항상 `b` |

- 표준 스트림: `stdin`, `stdout`, `stderr` (열지 않고 바로 사용).
- `stderr` 은 버퍼링이 없어 에러 메시지에 적합. 로그도 `stderr` 로.

## 2. 읽기 방법들

```c
// 한 줄씩 (텍스트) — 가장 흔함
char buf[4096];
while (fgets(buf, sizeof buf, fp) != NULL) {
    // buf 에 개행문자 '\n' 이 포함됨(줄이 버퍼보다 짧을 때). 제거하려면:
    buf[strcspn(buf, "\n")] = '\0';
}
// fgets 는 버퍼가 꽉 차면 줄 중간에서 끊음 → 남은 부분은 다음 호출에

// 바이트 블록 (바이너리)
unsigned char chunk[65536];
size_t got;
while ((got = fread(chunk, 1, sizeof chunk, fp)) > 0) {
    process(chunk, got);          // got 는 실제로 읽은 바이트 (< 요청일 수 있음)
}
if (ferror(fp)) { /* 진짜 에러 */ }
// feof(fp) 는 "읽기를 시도해서 EOF를 만난 뒤"에 참. 루프 조건으로 쓰지 마라.

// POSIX getline (동적 버퍼, 줄 길이 무제한) — 표준 C는 아니지만 리눅스/macOS 있음
char *line = NULL; size_t cap = 0; ssize_t len;
while ((len = getline(&line, &cap, fp)) != -1) { ... }
free(line);
```

`./bin/13_wc` 는 `wc` 클론으로 줄/단어/바이트를 셉니다.

## 3. 쓰기와 버퍼링

```c
fprintf(fp, "%s = %d\n", key, value);
fwrite(data, 1, n, fp);           // 반환값 = 쓴 원소 수. < n 이면 디스크 꽉참 등

// 버퍼링: 데이터가 즉시 디스크에 안 갈 수 있다
fflush(fp);                        // 버퍼를 밀어냄 (아직 OS 캐시엔 있을 수 있음)
// 진짜 디스크까지: POSIX fsync(fileno(fp)) (충돌 안전성이 필요할 때)
```

**크래시 디버깅 함정**: `printf("A"); crash();` 에서 "A"가 안 보이면 버퍼 때문입니다.
`stderr` 로 찍거나 `setvbuf(stdout, NULL, _IONBF, 0)` 로 버퍼를 끄세요.

## 4. `errno` 규약

```c
#include <errno.h>
#include <string.h>

errno = 0;                         // 호출 전에 0으로
FILE *fp = fopen(path, "r");
if (!fp) {
    fprintf(stderr, "%s 열기 실패: %s\n", path, strerror(errno));  // EACCES, ENOENT ...
    // 또는 perror(path);
}
```

규칙:
- `errno` 는 **함수가 실패를 알린 뒤에만** 의미가 있습니다. 성공 시 값은 정의 안 됨.
- 성공한 함수도 `errno` 를 바꿀 수 있습니다. 그래서 "실패 반환 확인 → 즉시 errno 읽기".
- `errno` 는 스레드별로 따로입니다(TLS). 스레드 안전.
- `strerror` 는 정적 버퍼 → 스레드 안전 아님. `strerror_r` (POSIX) 사용.

## 5. C의 에러 처리 관용구

C에는 예외가 없습니다. 세 가지 방식이 쓰입니다.

### (a) 반환값으로 상태, 출력은 포인터 인자로
```c
int parse_config(const char *path, Config *out);   // 0 = 성공, 음수 = 에러 코드
```

### (b) 특수 반환값 (`NULL`, `-1`, `SIZE_MAX`) + `errno`
```c
FILE *fopen(...);        // NULL + errno
ssize_t read(...);       // -1 + errno
```

### (c) 에러 코드 enum + 문자열 변환 함수
```c
typedef enum { E_OK, E_NOMEM, E_IO, E_PARSE } Err;
const char *err_str(Err e);
```

### 그리고 정리는 `goto cleanup` (4장 복습)

```c
int load(const char *path, char **out, size_t *out_len) {
    int rc = E_IO;
    FILE *fp = NULL;
    char *buf = NULL;

    fp = fopen(path, "rb");
    if (!fp) return E_IO;

    if (fseek(fp, 0, SEEK_END) != 0) goto done;
    long size = ftell(fp);
    if (size < 0) goto done;
    rewind(fp);

    buf = malloc((size_t)size + 1);
    if (!buf) { rc = E_NOMEM; goto done; }

    if (fread(buf, 1, (size_t)size, fp) != (size_t)size) { rc = E_IO; goto done; }
    buf[size] = '\0';

    *out = buf;
    *out_len = (size_t)size;
    buf = NULL;                     // 소유권 이전 → 아래 free 안 되게
    rc = E_OK;

done:
    free(buf);                      // 실패 시 정리, 성공 시 NULL(무해)
    fclose(fp);
    return rc;
}
```

`./bin/13_readfile` 이 이 패턴의 완성형입니다. 22장 캡스톤이 이걸 재사용합니다.

> **주의**: `ftell`/`fseek` 로 파일 크기 구하기는 일반 파일에서만 신뢰할 수 있습니다.
> 파이프/소켓/특수 파일에선 안 됩니다. 그런 경우 "읽으면서 동적으로 버퍼 확장".
