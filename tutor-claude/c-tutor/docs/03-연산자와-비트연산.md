# 03. 연산자와 비트 연산

> 목표: 연산자 우선순위의 함정, 단락 평가, 그리고 **실무에서 진짜 쓰는 비트 연산**(플래그·마스크·시프트).

---

## 0. 초등학생 버전 비유

스위치 8개가 한 줄로 붙어 있는 전등 패널을 생각하세요. 각 스위치는 켜짐(1)/꺼짐(0).
- "3번 스위치만 켜기" → **OR 마스크**
- "5번 스위치만 끄기" → **AND 마스크(반전)**
- "2번 스위치 상태 뒤집기" → **XOR**
- "모든 스위치를 왼쪽으로 한 칸씩 밀기" → **시프트** (× 2 와 같음)

비트 연산은 "정수 한 개를 스위치 여러 개의 묶음으로 다루는" 기술입니다.
설정 플래그, 권한 비트(`rwxr-xr-x`), 색상(RGBA), 네트워크 헤더가 전부 이렇게 동작합니다.

## 1. 꼭 외워야 하는 우선순위 함정

| 잘못 쓴 코드 | 실제 해석 | 고침 |
|---|---|---|
| `if (a & MASK == 0)` | `a & (MASK == 0)` — `==` 가 `&` 보다 먼저! | `if ((a & MASK) == 0)` |
| `*p++` | `*(p++)` — 값을 읽고 포인터 증가 (보통 이게 의도) | 의도가 `(*p)++` 면 괄호 |
| `a << 1 + 2` | `a << (1 + 2)` = `a << 3` | `(a << 1) + 2` |
| `x = y = 0` | 오른쪽부터: `y=0`, 그다음 `x=y` | (이건 정상 동작) |
| `a ? b : c = d` | `a ? b : (c = d)` | 삼항의 결과에 대입 불가 |

> **실무 규칙**: 비트 연산자(`& | ^ << >>`)를 비교/논리 연산자와 섞으면 **무조건 괄호**.
> 컴파일러도 `-Wparentheses` 로 경고합니다.

## 2. 논리 연산과 단락 평가 (short-circuit)

`&&` 와 `||` 는 **왼쪽만으로 결과가 정해지면 오른쪽을 평가하지 않습니다.**

```c
if (p != NULL && p->value > 0)   // p 가 NULL 이면 p->value 는 아예 실행 안 됨 → 안전
if (denominator != 0 && numerator / denominator > 1)  // 0으로 나누기 방지
if (init() || fallback())        // init() 이 참(성공)이면 fallback() 안 부름
```

이 순서 의존성은 **버그의 원인도 됩니다**: 부수 효과가 있는 함수를 `&&` 오른쪽에 두면
조건에 따라 호출되거나 안 되거나 합니다.

`&` 와 `|` (비트 연산)는 단락 평가가 **없습니다**. 양쪽 다 평가됩니다.

## 3. 실무 비트 연산 레시피

`./bin/03_flags` 가 아래를 전부 실행합니다.

```c
enum {
    PERM_READ  = 1 << 0,   // 0b001 = 1
    PERM_WRITE = 1 << 1,   // 0b010 = 2
    PERM_EXEC  = 1 << 2,   // 0b100 = 4
};

unsigned flags = 0;

flags |=  PERM_READ | PERM_WRITE;   // 켜기 (set)
flags &= ~PERM_WRITE;               // 끄기 (clear)
flags ^=  PERM_EXEC;                // 토글 (toggle)

if (flags & PERM_READ)   { ... }    // 검사 (test) — 0이 아니면 켜져 있음
int on = (flags & PERM_EXEC) != 0;  // 0/1 로 정규화
```

### 시프트

```c
x << n   // x * 2^n  (단, 부호 있는 x 가 음수이면 UB. 부호 없는 타입 권장)
x >> n   // 부호 없으면 논리 시프트(0 채움). 부호 있고 음수면 구현 정의(보통 산술 시프트)
1u << 31 // OK.  1 << 31 은 int 오버플로우로 UB! 시프트엔 unsigned 리터럴을 써라
```

### 자주 쓰는 관용구

```c
x & (x - 1)          // 최하위 1비트를 제거. 결과가 0이면 x 는 2의 거듭제곱
x & -x               // 최하위 1비트만 남김
(x + 7) & ~7u        // x 를 8의 배수로 올림 정렬 (9장 메모리 정렬에서 재등장)
n & (ALIGN - 1)      // ALIGN 이 2의 거듭제곱일 때 n % ALIGN 과 같음 (더 빠름)
count = __builtin_popcount(x)   // 켜진 비트 수 (GCC/Clang 확장; C23 <stdbit.h>)
```

## 4. 대입 연산자와 `+= 등`

`a += b` 는 `a = a + b` 와 같지만 **`a` 를 한 번만 평가**합니다.
`arr[f()] += 1;` 에서 `f()` 는 한 번만 호출됩니다. `arr[f()] = arr[f()] + 1;` 는 두 번.

---

## 5. 평가 순서와 시퀀스 포인트 (맛보기, 16장에서 정식으로)

```c
int i = 0;
a[i] = i++;          // UB! 같은 변수 i 를 한 문장에서 읽고 쓰는데 순서 미정
printf("%d %d", i++, i++);  // UB! 인자 평가 순서 미정
f(g(), h());         // g 와 h 중 누가 먼저? 미정 (하지만 UB는 아님)
```

**규칙**: 한 문장에서 같은 변수를 두 번 바꾸거나, 바꾸면서 (그 대입과 무관하게) 읽지 마라.
헷갈리면 문장을 쪼개라.
